# ekantipur-scraper

Playwright-based scraper for [ekantipur.com](https://ekantipur.com): it collects the top five articles from the Entertainment (मनोरञ्जन) section and the Cartoon of the day, then writes structured JSON. Built for the **Audio Bee — Data Extraction Intern** technical assessment (Python, `uv`, Playwright).

## Requirements

- Python **3.12** or **3.13** (see `requires-python` in `pyproject.toml`)
- [uv](https://docs.astral.sh/uv/) package manager
- Chromium (installed via Playwright; see setup)

## Setup

### Windows (PowerShell)

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Then in the project directory:

```powershell
uv sync
uv run playwright install chromium
```

### macOS / Linux

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
cd ekantipur-scraper
uv sync
uv run playwright install chromium
```

## Run

```bash
uv run python scraper.py
```

The script launches Chromium (`headless=False` in `scraper.py` so you can watch the run), visits the entertainment listing and the cartoon page, then writes **`output.json`** in the project root with UTF-8 and `ensure_ascii=False` so Nepali (Devanagari) text is preserved.

## Output (`output.json`)

```json
{
  "entertainment_news": [
    {
      "title": "...",
      "image_url": "https://...",
      "category": "मनोरञ्जन",
      "author": "..." 
    }
  ],
  "cartoon_of_the_day": {
    "title": "...",
    "image_url": "https://...",
    "author": "..."
  }
}
```

- **entertainment_news**: up to five items with title, full image URL, section label, and author (or `null` if missing).
- **cartoon_of_the_day**: single object for the daily cartoon (title, image URL, cartoonist/attribution when detectable).

## Project layout

| File | Role |
|------|------|
| `scraper.py` | Main Playwright script: navigation, waits, selectors, JSON write |
| `output.json` | Generated scrape result (recreated each run) |

| `prompts.txt` | Prompts used with Cursor / AI during development (assessment deliverable) |

`main.py` is a placeholder and is **not** the assessment entrypoint; use `scraper.py` as above.

## Tips

- If the site is slow, the script already uses `networkidle`, selector waits, and short delays; timeouts print warnings and continue where possible.
- Thumbnails may use lazy loading; the scraper prefers `data-src` then `src` on images.
- For selector debugging, use DevTools on ekantipur.com or temporarily use Playwright’s `page.pause()` while developing.
